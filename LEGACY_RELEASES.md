# Historical materials and releases

This repository preserves earlier research versions for traceability.

## v1.0.0

Early prediction-risk-propagation and exploratory materials. Some code paths under `simulation/extensions/` and older application scripts belong to this phase.

## v2.0.0

Feedback-aware recursive Q-learning materials, primarily under `simulation/feedback_aware/`.

These historical directories are retained so that prior Git tags and archived releases remain interpretable. They are not used to generate the current risk-propagation results unless a current documentation file explicitly says otherwise.

## v3.0.0

Journal-neutral reproducibility release for the current research on risk propagation under model selection and model averaging in recursive Q-learning.

Historical tags and previously published Zenodo records should not be rewritten or deleted. New scientific releases should use new Git tags and new version-specific Zenodo DOIs.
